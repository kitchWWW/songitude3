# Demo videos for App Review

Guideline 2.1 (Information Needed) on the 1.0 rejection asks for a video of the app running on a
physical device, showing background audio, location, and every permission request. These are the
recordings made for that.

| File | Recorded | Length |
|---|---|---|
| `sample-one.mp4` | 2026-09-09 21:51 | 2:36 |
| `sample-two.mp4` | 2026-09-09 21:55 | 3:45 |

Both were shot on Brian's iPhone 15 against **1.0 (9)**, Release, installed to a freshly wiped app
container so onboarding and the location prompt appear from a cold start.

The `.mp4` files are **not committed** — each is over GitHub's 100 MB file limit, so `.gitignore`
excludes them and only this note travels with the repo.

App Review needs a **URL**, not an attachment: host the chosen video somewhere public and put the
link in the Notes field of App Review Information. Apple requires a fresh video link on every
subsequent submission.
